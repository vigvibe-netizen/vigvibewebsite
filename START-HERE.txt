VIGVIBE — COMPLETE SITE. THIS IS THE WHOLE THING.
=================================================

You do not need to delete anything file-by-file. Replace the folder contents
in one move instead.


THE 6 STEPS
-----------

1. Unzip this. You get a folder called "site" containing:
   src/  public/  scripts/  astro.config.mjs  netlify.toml  package.json
   README.md  stackbit.config.ts  .gitignore

2. Open your cloned repo folder (vigvibewebsite) in Finder.

3. Select EVERYTHING inside it EXCEPT the folder named ".git"
   - Cmd-A to select all
   - Cmd-click ".git" to deselect it   (if you don't see .git, press
     Cmd-Shift-Period to show hidden files)
   - Cmd-Delete
   Do NOT delete the .git folder. That is what connects you to GitHub.
   Do NOT delete the repo folder itself.

4. Open the unzipped "site" folder, select everything inside it,
   and drag it into the now-empty repo folder.

5. Open GitHub Desktop. It will show a long list of changes — deletions
   and additions together. That is correct and expected.
   Summary: "Full site replace"
   Click "Commit to main", then "Push origin".

6. Netlify rebuilds in 2-3 minutes.


WHY THIS WORKS
--------------
Git tracks deletions the same way it tracks edits. By emptying the folder
and dropping in a clean copy, every file you wanted gone is recorded as a
deletion automatically. You never have to hunt down an individual file.
