steps:
  - title: Close every door but one
    body: Requests arrive by Slack, email, hallway, and calendar invite. Pick one channel and route the rest to it. This alone surfaces how much work was invisible.
  - title: Make five fields required
    body: Audience, deadline, channel, approver, and what success looks like. If a request cannot answer those, it is not ready to start.
  - title: Triage once a week, not continuously
    body: Thirty minutes, same slot, one person deciding. Continuous triage is just interruption with a nicer name.
  - title: Name one approver per request
    body: Feedback from four people in three tools is the single most expensive habit in creative work. One name on the line, others advise.
  - title: Measure one number
    body: Days from request to approved. Not hours logged, not tickets closed. If that number drops, the fix worked.

Most teams that ask for a workflow overhaul do not need one. They need five decisions made
and held for a month.

Run these in order. Each one takes less than a day to set up and the whole thing costs
nothing but the willingness to say no to the old habit.
